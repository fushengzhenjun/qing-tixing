# 轻提醒 QingTiXing

一款简洁、无广告、完全离线的到点提醒软件（Windows 桌面）。

## 下载安装
前往 [Releases 发布页](https://github.com/fushengzhenjun/qing-tixing/releases) 下载最新的
`QingTiXing-Setup-版本号.exe`，双击即可安装（当前用户安装，无需管理员权限）。

## 主要功能
- 单次、每天、工作日、每周、每月、每年、每 N 天等多种重复规则
- 按间隔循环：指定几点到几点、每隔 N 分钟（喝水、久坐提醒）
- 倒计时提醒；到点弹窗 + 铃声 + 振动，支持贪睡 5 / 10 分钟
- 四档提醒弹窗大小：紧凑、标准、醒目、全屏
- 五大分类与一键模板、多种铃声、夜间免打扰、全部暂停
- 浅色 / 深色 / 跟随系统
- 系统托盘后台常驻、开机自启动
- 数据本地保存，支持 JSON 导入导出
